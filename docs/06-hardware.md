# 06 — ฮาร์ดแวร์หน้าร้าน

## ภาพรวมการเชื่อมต่อ

```
   แท็บเล็ต / PC หน้าร้าน                   จอที่สอง (จอลูกค้า)
   ┌──────────────────┐                  ┌──────────────────┐
   │  เบราว์เซอร์ /pos  │ ─BroadcastChannel→│   /pos/display   │
   └────────┬─────────┘                  └──────────────────┘
            │ HTTP 127.0.0.1:9110
            ▼
   ┌──────────────────┐   USB / LAN / Serial   ┌──────────────┐
   │   Print Bridge   │ ─────────────────────→ │ เครื่องพิมพ์สลิป │
   └──────────────────┘                        └──────┬───────┘
                                                RJ11  │
                                               ┌──────▼───────┐
                                               │ ลิ้นชักเงินสด  │
                                               └──────────────┘
   เครื่องสแกนบาร์โค้ด → เสียบ USB ทำงานเหมือนคีย์บอร์ด (ไม่ต้องตั้งค่า)
```

## 1. เครื่องพิมพ์สลิป

### ทำไมต้องมี Print Bridge
เบราว์เซอร์ส่ง ESC/POS ไปเครื่องพิมพ์ USB/LAN ตรง ๆ ไม่ได้ และ `window.print()`
ก็ผ่านไดรเวอร์ระบบซึ่งเปิดลิ้นชักไม่ได้ Bridge เป็น Node process เล็ก ๆ
ที่ผูกกับ `127.0.0.1` เท่านั้น (เครื่องอื่นในเน็ตเวิร์กสั่งพิมพ์ไม่ได้)

### API
```
GET  /status   → { ok, platform, printerType, printers: [...] }
POST /print    → { data: "<base64 ESC/POS>", encoding: "base64" }
POST /drawer   → { pin: 0 | 1 }
```

### รัน
```bash
cd bridge
PRINTER_TYPE=network PRINTER_HOST=192.168.1.50 PRINTER_PORT=9100 node src/server.js
PRINTER_TYPE=usb     PRINTER_DEVICE=/dev/usb/lp0                  node src/server.js
PRINTER_TYPE=file                                                 node src/server.js  # โหมดทดสอบ
```

### ทางสำรอง 3 ชั้น (ตั้งในหน้า /pos/settings)
1. **Print Bridge** — เสถียรที่สุด เปิดลิ้นชักได้
2. **WebSerial** — Chrome/Edge บนคอมต่อเครื่องพิมพ์ USB/Serial ตรง (ต้องกดอนุญาตครั้งแรก)
3. **Browser print** — ผ่านไดรเวอร์ระบบ เปิดลิ้นชักไม่ได้ ใช้เป็นทางหนีสุดท้าย

### รุ่นที่แนะนำ
| รุ่น | การเชื่อมต่อ | หมายเหตุ |
|---|---|---|
| Epson TM-T82III / T88VI | USB + LAN | มาตรฐานอุตสาหกรรม ทนมาก มีพอร์ตลิ้นชัก |
| Xprinter XP-N160II / XP-Q200 | USB + LAN | ราคาย่อมเยา ใช้กันแพร่หลายในไทย |
| Star TSP143III | USB/LAN/BT | รองรับ iOS ดี |

ความกว้าง: 80 มม. = 48 คอลัมน์ (แนะนำ) · 58 มม. = 32 คอลัมน์

### ภาษาไทยบนสลิป
ระบบเข้ารหัสเป็น **TIS-620** (codepage 255 บนเครื่องพิมพ์ส่วนใหญ่ — คำสั่ง `ESC t 0x3d`)
และคำนวณความกว้างโดยไม่นับสระบน/ล่าง (`ั`, `ิ-ฺ`, `็-๎`)
เพื่อให้คอลัมน์ตัวเลขตรงกัน

> ตัวอักษรจีนพิมพ์บนเครื่อง ESC/POS ทั่วไปไม่ได้ (ต้องมี CJK firmware)
> ระบบจึงพิมพ์สลิปเป็นไทย/อังกฤษ ส่วนภาษาจีนใช้บนหน้าจอ

## 2. ลิ้นชักเงินสด

ต่อสาย RJ11 เข้าพอร์ต DK ด้านหลังเครื่องพิมพ์ เปิดด้วยคำสั่ง

```
ESC p m t1 t2     →  0x1B 0x70 0x00 0x32 0xC8
                     m  = 0 (pin 2) หรือ 1 (pin 5)
                     t1 = ระยะเวลาจ่ายไฟ 50 × 2ms
                     t2 = ระยะพัก 200 × 2ms
```

- **เปิดอัตโนมัติ** เมื่อบิลมีการรับเงินสด
- **เปิดเองโดยไม่ขาย** ต้องมีสิทธิ์ `pos.open_drawer` และบันทึก `cash_movements` + `audit_logs`
- ตั้งขา (pin 2/5) ได้ในหน้า `/pos/settings` เพราะลิ้นชักบางยี่ห้อใช้ขาที่ต่างกัน

## 3. จอลูกค้า (Customer Display)

เปิด `/pos/display` เป็นหน้าต่างที่สองแล้วลากไปจอที่ลูกค้าเห็น
ซิงก์ผ่าน `BroadcastChannel` (มี `localStorage` เป็นทางสำรอง) — ทำงานแม้ออฟไลน์

3 สถานะ:
- **ว่าง** → โลโก้ + "ยินดีต้อนรับ / Welcome / 欢迎光临"
- **กำลังขาย** → รายการสินค้าตัวใหญ่ + ยอดสุทธิขนาด 5xl
- **จบการขาย** → "ขอบคุณที่ใช้บริการ" + ยอดรวม + เงินทอน

ตั้งค่าจอคู่: Windows `Win + P` → Extend · macOS System Settings → Displays → Extended

## 4. เครื่องสแกนบาร์โค้ด

เสียบ USB ทำงานเป็น HID keyboard ทันที ไม่ต้องตั้งค่าอะไรในระบบ
ตั้งค่าที่ตัวสแกนให้เติม **Enter (CR)** ท้ายทุกครั้งที่ยิง

รองรับ: EAN-13, Code 128, QR (สำหรับ serial บางรุ่น)
ช่องค้นหาในหน้าขายโฟกัสอยู่ตลอด กด `/` เพื่อกลับไปที่ช่องได้ทุกเมื่อ

## 5. เครื่องที่ใช้ได้

| อุปกรณ์ | ใช้ได้ | หมายเหตุ |
|---|---|---|
| PC / mini PC + จอสัมผัส | ✅ แนะนำสำหรับสาขาหลัก | ต่อได้ทั้งเครื่องพิมพ์ ลิ้นชัก และจอลูกค้า |
| iPad / Android tablet | ✅ | ใช้เครื่องพิมพ์ LAN (Bridge รันบนมินิพีซีในร้าน) หรือ Bluetooth |
| โน้ตบุ๊ก | ✅ | เหมาะกับสาขาชั่วคราว/ออกบูท |
| มือถือผู้จัดการ | ✅ (เฉพาะหลังบ้าน) | ดู dashboard, อนุมัติ |

หน้าจอออกแบบตั้งแต่ 768px ขึ้นไปสำหรับหน้าขาย และ responsive เต็มรูปแบบสำหรับหลังบ้าน

## 6. ตู้ขายอัตโนมัติ (Vending)

ข้อมูลจริงมีสาขาแบบตู้ 2 จุด (Mega Bangna, BTS Siam) — `branches.branch_type = 'vending'`
ตู้เหล่านี้ไม่มีพนักงาน จึงตั้งค่าให้ POS เป็นโหมด kiosk และไม่ต้องเปิดกะ
(ยอดขายเข้าระบบผ่าน API ของผู้ให้บริการตู้ — ดู roadmap)
