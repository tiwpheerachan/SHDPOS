# 09 — UI / UX

## หลักการ

1. **ปุ่มที่ใช้บ่อยต้องใหญ่** — ปุ่มชำระเงินสูง 56px เต็มความกว้างคอลัมน์ตะกร้า
2. **นิ้วโป้งต้องถึง** — ปุ่มสำคัญอยู่ครึ่งล่างของหน้าจอ เหมาะกับแท็บเล็ตวางบนเคาน์เตอร์
3. **ตัวเลขต้องอ่านง่าย** — ใช้ `font-variant-numeric: tabular-nums` ทุกช่องเงิน ตัวเลขจึงเรียงตรงกัน
4. **สถานะต้องชัดโดยไม่ต้องอ่าน** — สี + ไอคอน + ข้อความ ไม่พึ่งสีอย่างเดียว
5. **ไม่มี modal ซ้อน modal เกิน 1 ชั้น**

## Design tokens

ทุกสีมาจาก CSS variable ชุดเดียว เปลี่ยนธีมทั้งระบบได้จากที่เดียว

```css
:root {                      /* ค่าเริ่มต้น = โหมดสว่าง */
  --c-bg: 246 247 250;       --c-surface: 255 255 255;
  --c-line: 226 231 238;     --c-ink: 16 24 40;
  --c-muted: 100 116 139;    --c-brand: 37 99 235;
  --c-ok: 22 163 74;         --c-warn: 217 119 6;
  --c-danger: 220 38 38;     --c-info: 2 132 199;
}
:root[data-theme="dark"] { … }
```

**ค่าเริ่มต้นคือโหมดสว่างเสมอ** — มีสคริปต์เล็ก ๆ ใน `<head>` ตั้ง `data-theme`
ก่อน React hydrate เพื่อไม่ให้จอกระพริบ

โหมด: สว่าง (ค่าเริ่มต้น) / มืด / ตามระบบ — จำค่าไว้ใน `localStorage`

## 3 ภาษา

ไทย (ค่าเริ่มต้น) · English · 中文
พจนานุกรมอยู่ที่ `web/src/lib/i18n/dict.ts` ไฟล์เดียว แยกตามหมวด (`common`, `pos`, `payment`, `admin`, …)

```tsx
const { t, pick, locale, setLocale } = useI18n();
t.pos.pay                                              // "ชำระเงิน" / "Pay" / "收款"
pick({ th: p.name_th, en: p.name_en, zh: p.name_zh })  // เลือกชื่อสินค้าตามภาษา
```

สลับภาษาได้จากแถบบนทั้งหน้าร้านและหลังบ้าน (จำค่าไว้ต่อเครื่อง)
ชื่อสินค้า/สาขา/หมวด มีคอลัมน์ `name_th` / `name_en` / `name_zh` ในฐานข้อมูล
> หมายเหตุ: สลิปพิมพ์เป็นไทย/อังกฤษ เพราะเครื่องพิมพ์ ESC/POS ทั่วไปไม่มีฟอนต์จีน

## คีย์ลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `F2` | ชำระเงิน |
| `F4` | พักบิล |
| `/` | ไปช่องค้นหา |
| `Esc` | ปิดหน้าต่างที่เปิดอยู่ |
| `Enter` ในช่องค้นหา | เพิ่มสินค้าที่ตรงกับบาร์โค้ด/SKU |

## สถานะที่ต้องสื่อให้ชัด

| สถานการณ์ | หน้าตา |
|---|---|
| ออฟไลน์ | แถบส้มใต้เมนู + จำนวนงานรอซิงก์ |
| กำลังซิงก์ | ไอคอนหมุนสีฟ้า |
| สต๊อกใกล้หมด | ป้ายสีส้มบนการ์ดสินค้า + ตัวเลขคงเหลือ |
| สินค้าหมด | ป้ายแดง + ไอคอนกล่องขีดฆ่า (ยังขายได้ แต่เตือน) |
| ต้องขออนุมัติ | กล่องเหลืองพร้อมไอคอนโล่ + ระบุว่าต้องระดับไหน |
| พิมพ์สลิปไม่สำเร็จ | กล่องแดง **แต่หัวข้อยังเป็น "ขายสำเร็จแล้ว"** + ปุ่มลองใหม่ |
| Serial ยังไม่ครบ | ปุ่ม `0/1` สีส้ม บนบรรทัดนั้น |

## หน้าจอลูกค้า

ตัวหนังสือใหญ่ (`clamp(16px, 1.6vw, 22px)` เป็นฐาน, ยอดสุทธิขนาด 5xl)
อ่านได้จากระยะ 1–2 เมตร ไม่มีข้อมูลที่ลูกค้าไม่ควรเห็น (ต้นทุน, กำไร, ชื่อพนักงาน)

## หลังบ้าน

Sidebar ซ้าย 240px (พับได้บนจอเล็ก) · เมนูถูกซ่อนอัตโนมัติตามสิทธิ์
แถบกรองด้านบนทุกหน้า: ช่วงเวลา × สาขา × แบรนด์ — จำกัดตาม data scope โดยอัตโนมัติ

### กราฟ
เขียนเป็น SVG เอง ไม่พึ่ง library:
- **Area** ยอดขายรายวัน + เส้นประเทียบช่วงก่อนหน้า
- **BarList** จัดอันดับสาขา/พนักงาน
- **Donut** สัดส่วนแบรนด์ / ช่องทางชำระ
- **Columns** ยอดขายรายชั่วโมง
- **Sparkline** เทรนด์ย่อในตาราง

จานสี 8 สีผ่านการตรวจ contrast ทั้งโหมดสว่างและมืด ทุกกราฟมีทั้งสีและตัวเลขกำกับ
(ไม่บังคับให้แยกด้วยสีอย่างเดียว)

## Accessibility

- ขนาดปุ่มขั้นต่ำ 44×44px ตามแนวทาง touch target
- contrast ตัวอักษรหลักผ่าน WCAG AA ทั้งสองโหมด
- ทุก input มี `<label>` และ modal ปิดด้วย `Esc` ได้
- ไม่ใช้สีอย่างเดียวสื่อความหมาย (มีไอคอน/ข้อความประกอบเสมอ)
- ฟอนต์: Noto Sans Thai / IBM Plex Sans Thai (รองรับไทย + ละติน + จีน)
