# SHD POS — แอปตัวหุ้มสำหรับ Sunmi (D2s)

แอปนี้ **ไม่ใช่ POS ตัวใหม่** แค่เปิดเว็บระบบเราเต็มจอ แล้วเพิ่ม 2 อย่างที่เบราว์เซอร์ทำไม่ได้:

1. **พิมพ์ใบเสร็จ** ด้วยเครื่องพิมพ์ในตัวของ Sunmi อัตโนมัติ ไม่มีหน้าต่างให้กด
   - เว็บวาดใบเสร็จเป็นรูป ภาษาไทยจึงออกถูกแน่นอน
   - พิมพ์เสร็จตัดกระดาษเองถ้าเครื่องมีมีดตัด
2. **จอลูกค้า** บนจอที่สองของ D2s เปิดหน้า `/pos/display` แยกจากจอพนักงาน
   - แสดงตะกร้า ยอดเงิน QR พร้อมเพย์ และแบนเนอร์ตอนว่าง

หน้าจอ ราคา และฟีเจอร์ทั้งหมดยังอยู่บนเว็บ แก้เว็บ/deploy แล้วเครื่องอัปเดตตามเอง ไม่ต้องลงแอปใหม่

## ดาวน์โหลดไฟล์ติดตั้ง (APK)

GitHub → repo → แท็บ **Actions** → workflow **android-shell** → รันล่าสุด (สีเขียว) → **Artifacts** → `shd-pos-shell`

- แตกไฟล์ zip จะได้ไฟล์ `.apk`
- อยากเปลี่ยน URL เริ่มต้น: Actions → android-shell → **Run workflow** → ใส่ `app_url`

## ติดตั้งบนเครื่อง Sunmi

1. ก๊อป `.apk` ลงเครื่องด้วยแฟลชไดรฟ์ USB หรือดาวน์โหลดผ่านเบราว์เซอร์ในเครื่อง
2. เปิดไฟล์ แล้วกดอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" ถ้าเครื่องถาม
3. เปิดแอป **SHD POS** แล้วล็อกอินตามปกติ
4. ที่หน้าร้าน → ตั้งค่า จะเห็นกรอบสีเขียว "เปิดผ่านแอป SHD POS บน Sunmi" บอกสถานะเครื่องพิมพ์และจอลูกค้า → กด **ทดสอบพิมพ์**

## ตั้งค่าในแอป

แตะ **มุมซ้ายบน 5 ครั้งติดกัน** จะเปิดหน้าตั้งค่า:
- **URL ระบบ:** ค่าเริ่มต้น `https://shdpos.onrender.com`
- สถานะเครื่องพิมพ์ / จอลูกค้า
- เวอร์ชัน WebView และ Android

## อัปเดตแอป (สำคัญ)

ถ้าไม่ได้ตั้งคีย์เซ็นถาวร แต่ละรอบที่ build จะเซ็นด้วยคีย์ใหม่ → ต้องลบแอปเก่าก่อนติดตั้ง ซึ่งจะ **ลบบิลออฟไลน์ที่ยังไม่ซิงก์** ด้วย

**ก่อนลบแอปเก่า:** ตรวจว่าหน้าตั้งค่ามี "รอซิงก์ 0" ก่อนทุกครั้ง

**ตั้งคีย์ถาวร** (ทำครั้งเดียว — หลังจากนั้นติดตั้งทับได้เลย):

```bash
keytool -genkeypair -v -keystore shell.jks -alias shdpos -keyalg RSA -keysize 2048 -validity 10000
base64 -i shell.jks | pbcopy   # ค่า SHELL_KEYSTORE_B64
```

GitHub → Settings → Secrets and variables → Actions → เพิ่ม 4 ค่า:
- `SHELL_KEYSTORE_B64`
- `SHELL_KEYSTORE_PASSWORD`
- `SHELL_KEY_ALIAS` (= `shdpos`)
- `SHELL_KEY_PASSWORD`

เก็บไฟล์ `shell.jks` ไว้ให้ดี ห้ามใส่ลง repo

## หมายเหตุทางเทคนิค

- เว็บรู้ว่าเปิดในแอปจาก `window.SHDShell` (`web/src/lib/printing/shell.ts`) ถ้าเปิดในเบราว์เซอร์ปกติ ระบบทำงานแบบเดิมทุกอย่าง
- **พิมพ์:**
  - `printEscPos()` → `renderReceiptPng()` → `SHDShell.printImageAsync()`
  - แอปใช้ SDK `com.sunmi:printerlibrary` พิมพ์ทีละใบตามลำดับ และแจ้งผลกลับ (เช่น กระดาษหมด ฝาเปิด)
- **จอลูกค้า:** `pushDisplay()` → `SHDShell.display(json)` → แอปเรียก `window.__shdDisplay(payload)` ในหน้า `/pos/display` บนจอที่สอง
- **ความปลอดภัย:**
  - สั่งพิมพ์ได้เฉพาะหน้าเว็บของระบบเรา
  - ลิงก์ภายนอกเปิดด้วยแอปอื่น
  - อนุญาตเฉพาะโดเมนระบบ + `*.shd-technology.co.th` (SSO)
- **ต้องลองบนเครื่องจริง:**
  - เวอร์ชัน WebView ของเครื่อง (ดูได้ในหน้าตั้งค่า) — ถ้าเก่ามาก บางหน้าอาจแสดงผลเพี้ยน
  - ขนาดตัวอักษรบนกระดาษจริง
